## Information required before charger matching

A charger should be selected from the battery system data, not only from the nominal battery voltage. Before requesting a quotation, prepare:

1. Battery nominal voltage and maximum charging voltage.
2. Battery chemistry, such as Li-ion, LiFePO4 or lead-acid.
3. Required charging current and acceptable charging time.
4. Connector photo, pin definition and polarity.
5. Application and operating environment.
6. Input plug and target market.
7. Estimated order quantity and branding requirements.

Incorrect voltage, connector polarity or charging profile can damage a battery system. Always confirm the battery pack specification and BMS requirements before production.

## Typical application ranges

| Application | Common matching considerations |
| --- | --- |
| E-bike and e-scooter | Compact housing, connector compatibility, replacement-program consistency |
| Mobility equipment | Stable CC/CV charging, accessible connector and indicator behavior |
| AGV/AMR and cleaning machines | Duty cycle, communication needs, installation space and cable routing |
| Golf carts and utility vehicles | Higher power, environmental protection and robust connectors |
| Marine and industrial systems | Cooling, enclosure, input supply, protection and installation method |
